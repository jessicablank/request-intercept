One-time setup (why an extension is needed)

Browsers do not let one website change the network traffic of another website, so this page works together with a small companion Chrome/Edge extension. The extension stores the rules you create here and, on every site, swaps matching fetch/XMLHttpRequest responses for the one you configured.

  1. Download the extension (.zip) and unzip it.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and select the unzipped folder.
  4. Reload this page – the banner above should turn green.
